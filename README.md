# Diplom_2
Проведено API тестирование приложения Stellar Burger
Конфигурация среды, в которой проводилось тестирование:
Java 11
JUnit 4.13.2
RestAssured 5.5.5

Разработаны автотесты для тестирования следующего функционала:
1. Создание пользователя
- Создание уникального пользователя
- Создание пользователя, который уже зарегистрирован
- Создание пользователя с незаполненным одним из обязательных полей
2. Логин пользователя
- Вход под существующим пользователем
- Вход с неверным логином и паролем
3. Создание заказа
- С авторизацией
- Без авторизации
- С ингредиентами
- Без ингредиентов
- С неверным хешем ингредиентов

Сгенерирован отчет Allure
Для запуска тестов применять mvn clean test
Для запуска отчета применять mvn allure:serve
